# SneakHub — Sneaker Store

Client-server sneaker storefront with product management, shopping cart, checkout, OTP interface and payment controller.

## Project structure

- `client/src/pages/`
- `client/src/admin/`
- `client/src/services/api.js`
- `server/controllers/`
- `readme.txt`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/SneakHub.git
cd SneakHub
```

Install dependencies in `client` and `server`, configure local database and payment settings, start the server using its package scripts, then run `npm run dev` in `client`.
